# SMR — แบบฟอร์มลงทะเบียนงานสัมมนา

แบบฟอร์มลงทะเบียนเข้าร่วมงานสัมมนา ทำงานฝั่งเบราว์เซอร์ล้วน (ไฟล์ HTML เดียวจบ)
เก็บข้อมูลไว้ในเครื่องผ่าน `localStorage` ของเบราว์เซอร์

## ไฟล์
- `seminar-form.html` — ตัวฟอร์ม + หน้าดูรายชื่อผู้ลงทะเบียน (มีล็อกอินผู้ดูแล)
- `serve.js` — เว็บเซิร์ฟเวอร์ static เล็ก ๆ สำหรับเปิดผ่าน `localhost`

## วิธีเปิดใช้งาน
เปิดตรง ๆ ด้วยเบราว์เซอร์ก็ได้ (ดับเบิลคลิก `seminar-form.html`)
หรือเปิดผ่าน localhost:

```bash
node serve.js          # พอร์ตเริ่มต้น 8080
node serve.js 8090     # กำหนดพอร์ตเองได้
```

แล้วเปิด http://localhost:8080

## ความสามารถ
- ฟอร์มลงทะเบียนครบ 14 หัวข้อ พร้อมตรวจสอบข้อมูลที่จำเป็น
- ตรวจอีเมล/เบอร์โทรแบบเรียลไทม์ และกันข้อมูลซ้ำ
- หน้าผู้ดูแล (ใส่รหัสผ่าน) สำหรับดูรายชื่อ ค้นหา ลบ และดาวน์โหลด CSV
